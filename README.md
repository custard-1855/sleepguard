# SleepGuard

作業がきりよく終わらず、気づくと深夜になっている人のための Mac / Android 用ツールです。
Mac は 22:30 から入浴を促す文面を画面いっぱいに出し、0時からは就寝を促す文面を出します。Android は 22時に入浴を促し、0時以降も使っていたら画面をロックします。

## 方針

- **作業は壊さない**: Mac の全画面表示は最初の15秒だけ操作を受け止め、そのあとは半透明になって下のアプリをそのまま操作できます。Android の画面ロックは画面を消してパスワードを求めるだけで、スリープはしません。tmux の中のジョブ、ビルド、ダウンロード、ssh 接続などはそのまま動き続けます。
- **音は鳴らさず、ネットも遮断しない**: 画面の表示だけで促します。
- **解除対策はしない**: 手間はかかりますが、止めたいときは止められます(Mac の就寝の全画面表示は30秒たてばボタンで閉じられます。入浴の表示は「入浴済み」を押すか離席するまで残りますが、プロセスを kill すればすぐ消えます。Android の「停止」は3回の確認のあと押せます。0時〜6時は「停止」を押せませんが、確認画面から電話や音声などのアプリは開けます)。勢いで押せないようにはしますが、ユーザー補助をオフにする・アンインストールするといった止め方は塞ぎません。強制ではなく、区切りをつけるきっかけを作るためのものです。
- **現地時間で判定**: 時刻は端末のタイムゾーン設定で判定するので、出張や旅行先でもそのまま使えます。

## スケジュール

| 時刻 | Mac | Android |
|---|---|---|
| 22:00〜 | (22:30 まで何もしない) | 使っている間、15分おきに通知。「入浴済み」を押すと今夜はもう出ない |
| 22:30〜 | 使っている間、10分おきに入浴を促す文面を全画面に出す。この画面は「入浴済み」を押すか15分離席するまで残り、どちらかで今夜はもう出ない | 同上 |
| 23:50 | 同上 | 予告の通知 |
| 0:00〜 | 使っている間、15分おきに就寝を促す文面を全画面に出す | 使っていたら通知し、10分後も使っていたら確認画面を出してロック。以後6時まで、ロック解除するたびに確認画面 |
| 1:00〜 | 使っている間、10分おきに就寝を促す文面を全画面に出す。6時まで。画面ロックはしない | 同上 |
| 使っていない | 何もしない | 何もしない |

Mac は無操作が2分未満なら「使っている」とみなします。Mac の時間帯は文面ファイルの見出しで変えられます(後述)。

## Mac

```sh
cd mac
sudo ./install.sh      # 入れる
sudo ./uninstall.sh    # 外す
```

`install.sh` は次の3つを root:wheel の所有で置き、launchd(root)から `sleepguard.sh` を毎分実行させます。常駐するプロセスはなく、時間帯の外ではスクリプトが時刻を見てすぐ終わります。全画面アプリ `sleepguard-show` は `SleepGuardShow.swift` を `install.sh` が swiftc でコンパイルしたもので、Command Line Tools(`xcode-select --install`)が必要です。

- `/Library/Application Support/SleepGuard/sleepguard.sh`
- `/Library/Application Support/SleepGuard/sleepguard-show`
- `/Library/LaunchDaemons/com.sleepguard.agent.plist`

あわせて、文面ファイル `mac/messages.md` を `~/.config/sleepguard/messages.md` にコピーします(すでにあれば触りません)。`uninstall.sh` はこの文面ファイルと、表示した文の記録(`~/.config/sleepguard/shown/`)は消しません。

以前の版は `/usr/local/sleepguard` に置いていました。`/usr/local` は Homebrew の環境で一般ユーザーの所有になっていることがあり、root で動くスクリプトをすり替えられる恐れがあるため移しました。`install.sh` は旧配置先が残っていれば消します。`uninstall.sh` は新旧どちらの配置先も、夜ごとの記録(`/var/db/sleepguard`)も消します。

### 全画面表示の流れ

1. 1秒かけて現れます。ほぼ黒の背景に文面を大きく、下に現在時刻を小さく出します。全ディスプレイに、フルスクリーンのアプリや動画の上にも出ます。
2. 最初の15秒は、クリックもキー入力も全部受け止めて下のアプリには届けません。Cmd+Q も効きません。
3. 15秒たつと背景が半透明になり、クリックもキー入力も下のアプリに素通しします。文面は見えたままです。まだ閉じられません。
4. 30秒たつと画面下に小さなバーが出ます。就寝の画面なら「閉じる」、入浴の画面なら「入浴済み」だけです。閉じられるのはこのボタンだけで、Esc では閉じません。
5. 就寝の画面は、2分なにもしなければ自動で閉じます。入浴の画面には「閉じる」が無く、保存などを済ませてお風呂へ行くまで残ります。15分離席したら、お風呂に行ったとみなして入浴済みとして閉じます。

### 文面ファイル

`~/.config/sleepguard/messages.md` を編集すると、次の表示から反映されます。install し直す必要はありません。

```markdown
## 22:30に表示
- お風呂に入ろう. その後はゆっくり本でも読んで, よく寝よう
- 今のうちにお風呂に入って. そうすれば後でじっくり本が読める

## 0:00以降に表示
- 早く寝て, 明日を良い一日にできるよう備えよう
- もう寝ましょう. おふとん天国に還るのです
```

- `## ` で始まり `H:MM` の時刻が続く見出しが、時間帯の始まりです。時刻のあとの文字は自由です。その時刻から次の見出しの時刻まで(最後の見出しは 5:59 まで)がその時間帯になります。最初の見出しより前の時刻には何も出しません。
- 0:00 より前(正午以降)に始まる時間帯は「入浴」扱いで、「入浴済み」ボタンと15分離席の判定が付きます。0:00 以降に始まる時間帯は「就寝」扱いで、閉じるだけです。
- `- ` で始まる行が1つの文です。1回の表示に1文をランダムに出し、その夜のうちは同じ文を繰り返しません。全部出し切ったら、また全部から引き直します。
- 時刻でない見出し(`## メモ` など)や、範囲外の時刻(`## 25:00`)は無視します。該当する時間帯に文が1つも無ければ、組み込みの1文を出します。
- root で動く `sleepguard.sh` が読むのは見出しの時刻だけで、文面の中身を読むのはユーザー権限で動く `sleepguard-show` だけです。

### 見た目を確かめる(プレビュー)

```sh
cd mac
./preview.sh                 # 22:30 の時間帯の文面を、本番と同じ時間で出す
./preview.sh 0:00 --quick    # 0:00 の時間帯。待ち時間を 2秒・4秒・20秒に縮める
./preview.sh --text "試したい文"   # ファイルに書く前に、文の長さが収まるか見る
```

一般ユーザーで実行します。本物の `~/.config/sleepguard/messages.md` を読みますが、出した文の記録は書きません。バイナリは `mac/.build/` に置き、`SleepGuardShow.swift` を直したときだけコンパイルし直します(初回だけ数十秒かかります)。

### 時刻や間隔を変える

時間帯の始まりは文面ファイルの見出しで変えます。間隔などは `sleepguard.sh` 冒頭の設定欄で変えられます。変えたら `sudo ./install.sh` をもう一度実行します。

| 変数 | 既定値 | 意味 |
|---|---|---|
| `BATH_INTERVAL` | 600 | 入浴の時間帯に文面を出す間隔(秒) |
| `BATH_AWAY` | 900 | これだけ離席したら入浴済みとみなす(秒)。表示中の画面もこれで閉じる |
| `SLEEP_INTERVAL` | 900 | 就寝の時間帯に文面を出す間隔(秒) |
| `LATE_START` | 100 | この時刻以降は `LATE_INTERVAL` おきにする(HHMM) |
| `LATE_INTERVAL` | 600 | `LATE_START` 以降に文面を出す間隔(秒) |
| `LATE_END` | 559 | 最後の時間帯の終わり(HHMM) |
| `ACTIVE_IDLE` | 120 | 無操作がこの秒数未満なら使用中とみなす |

時刻は HHMM を数値で書きます。先頭の0は付けません(1:00 なら `100`)。

### ログと動作確認

- ログ: `/var/log/sleepguard.log`。表示した文も `shown:` として残ります。
- 一般ユーザーで実行すると、時刻と無操作時間を指定して、全画面アプリを起動せずログだけ出せます。`SG_DRY_RUN=1` と `SG_STATE_DIR` は必須で、どちらかが欠けていると何もせず終了します。`SG_MESSAGES` に文面ファイルを指定します(見出しの時刻だけ読みます)。`SG_SHOW_RC=2` を付けると「入浴済み」が押されたことに、`SG_SHOW_RC=3` を付けると表示中に離席して閉じたことにできます。root で実行したときは `SG_*` をすべて無視して本番どおりに動くので、`sudo` は付けないでください。

  ```sh
  SG_DRY_RUN=1 SG_USER=$USER SG_STATE_DIR=$(mktemp -d) SG_IDLE=5 SG_MESSAGES=messages.md \
    SG_NOW=$(date -j -f "%Y-%m-%d %H:%M" "2026-10-13 01:05" +%s) ./sleepguard.sh
  ```

### テスト

```sh
cd mac
./test.sh
```

一般ユーザーで実行します(`sudo` は付けません)。上の dry run で時刻・無操作時間・ログイン中のユーザー・文面ファイルの見出しを変えながら `sleepguard.sh` を呼び、ログに出た表示と入浴の判定を確かめます。ケースごとに一時ディレクトリを使うので、インストール済みの状態には触れません。ケースごとに PASS/FAIL を表示し、1件でも失敗すると終了コードが0以外になります。全画面アプリの見た目は `./preview.sh` で確かめます。

## Android

1. Android Studio で `android` フォルダを開き、同期が終わったら実機を繋いで実行します(minSdk 28 = Android 9 以上)。
2. アプリを開いて、上から順に押します。
   - 「1. 通知を許可」
   - 「2. ユーザー補助を有効にする」→「SleepGuard」を有効にします。通知も画面ロックもこのユーザー補助サービスが行うので、オフだと何も動きません。Android 13 以降で灰色になって押せない場合は、「設定 → アプリ → SleepGuard → 右上のメニュー → 制限付き設定を許可」をしてから戻ってください。
   - 「3. 開始」
   - 夜中に使うアプリがあれば、「音声のアプリを選ぶ」「Cosenseのアプリを選ぶ」で選んでおきます(任意。0時〜6時は選べません)。Cosense はブラウザで「ホーム画面に追加」したもの(PWA)を選びます。ブラウザ本体を選ぶと、ブラウザで何を見ていてもロックされなくなります。
   - 端末の「緊急SOS」(電源ボタンを素早く5回押す)を有効にしておいてください。ロック中に待たずに通報できるのは、これとロック画面の「緊急通報」だけです(ほかの連絡は、ロックを解除して確認画面の「電話をかける」から)。場所は機種で違い、「設定 → 安全と緊急」などにあります。押す回数も機種の設定に従います。
3. 常駐の通知は出ません。再起動やアプリの更新のあとも、システムがユーザー補助サービスを接続し直すので自動で動きます(「停止」を押したあとは、もう一度「開始」を押すまで動きません)。

### 外出モード

食事・移動・旅行などで夜に出かけるときに使います。アプリの「今夜は外出」か、22時の入浴の通知の「外出中」を押すと、確認が出ます。10秒待つと「外出する」が押せるようになり、押すと入ります(待っている途中で画面を離れたら取り消し)。0時〜6時は入れません。その夜だけ有効で、翌朝6時に自動で切れます(何泊かの旅行では毎晩入れます)。位置情報などでの自動判定はしません。

| 時刻 | 外出中 |
|---|---|
| 22:00〜 | 入浴の通知を出さない |
| 23:50 | 予告を出さない |
| 0:00〜 | 使っていたら一度だけ「外出中でも1時までには寝ましょう」と通知。ロックはしない |

外出中は「帰宅した」ボタンつきの通知が出たままになります。帰ったら、この通知かアプリの「帰宅した」を押します(外出モードのときだけ押せます)。

- 0時より前に押したら、普段の流れに戻ります(22時台なら入浴の通知も再開します)。
- 0時以降に押したら、1時以降に使っていたら通知し、10分後も使っていたら画面をロックします。1時以降に押したときは、押した時点からこの流れになります。

### ロック中の確認画面

0時以降にロックの対象になると、すぐロックする代わりに確認画面を出します。以後6時まで、ロックを解除するたびにこの画面が出ます。10秒操作しないか、戻る・ホーム・履歴で離れるとロックします。

- **ロックする**: すぐロックします。ロック画面には、電話と「緊急通報」の案内つきの通知が出ます。
- **音声を聴く** / **Cosenseを開く**: アプリ画面の「音声のアプリを選ぶ」「Cosenseのアプリを選ぶ」で選んだアプリを開きます。アプリを選んでいなければボタンは出ません。0時〜6時はアプリを選び直せません。アプリ画面には「選択済み」とだけ出て、アプリ名は表示しません。
- **電話をかける**: 端末の標準の電話のアプリを開きます。選ぶ手順はありません。110・119 はこれを通さず、ロック画面の「緊急通報」からもかけられます。
- **アラームを設定**: 端末の標準の時計のアプリを開きます。選ぶ手順はありません。時計のアプリが見つからないか、複数あって標準が決まっていなければボタンは出ません。

どのアプリも回数の制限はなく、開いたアプリが前面にあるあいだは時間に関係なくロックしません。ほかのアプリに移ると、また確認画面が出ます。ホーム画面と履歴の画面では出ないので、履歴からスワイプで閉じられます。

確認画面が出せなかったとき(端末の制限など)は、普段どおりロックします。仕様は `docs/gate-screen.md` にあります。

### 設定の変更と、やめるとき

- 時刻は `app/src/main/java/dev/sleepguard/Schedule.kt` にまとまっています。
- 動作確認は `Schedule.kt` の時刻を数分後に変えてビルドするのが早いです。
- やめるときはアプリの「停止」を押すか、アンインストールします。「停止」は文言を変えて3回確認し、そのたびに「停止する」と「やめる」の左右が入れ替わります。途中で「やめる」を押すか画面を離れたら最初からです。0時〜6時は押せません。
- アプリが持つ権限は、通知とユーザー補助(画面ロックと、時間割の評価)だけです。ユーザー補助は画面の内容を読み取らない設定で、画面の切り替えのイベントから前面にあるアプリの名前だけを読みます(確認画面から開いたアプリを使っているかの判定のため)。ネット接続の権限は持っていないので、利用状況が外に送られることはありません。
