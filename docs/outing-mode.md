# 外出モード 仕様(Android)

2026-10-25 に合意した仕様。同日に実装した。

## 目的

食事・移動・旅行などで夜に出かけているとき、入浴の通知と1時のロックが邪魔・危険にならないようにする。
外にいても寝る時刻の目安は伝え、帰宅後は見守りに戻る。

## 全体

- モードは1つ(食事・移動・旅行で共通)
- 対象は Android だけ。Mac は変えない(外出中は無操作なので何も起きないため)
- 入るのは手動だけ。位置情報や Wi-Fi による自動判定はしない(権限を増やさない)
- その夜だけ有効。翌朝6時に自動で切れる。何泊かの旅行では毎晩入れる

## 「夜」の区切りを6時にする

- `Schedule.nightOf` の区切りを正午から6時(`LATE_END`)に変える。6時を過ぎて押せば、その日の夜に効く
- これに伴い、出したままの入浴の通知を消す条件を「22時より前に、入浴の通知を出したままなら消す」(`bathShownNight != ""`)に単純化する
  - いまの条件(`bathShownNight == night`)のまま区切りだけ変えると、22時台に通知を出して朝6時すぎまで tick が来なかった場合に、通知が翌日まで残る

## 入口と出口

- 入る
  - 22時の入浴の通知に「外出中」ボタンを足す。本文にも「外出中なら『外出中』を押してください」の旨を足す
  - アプリ画面に「今夜は外出」ボタンを足す
  - 入ったら、出ている入浴の通知を閉じる
  - 1時〜6時は入れない(アプリ画面の「今夜は外出」も押せない)
  - (2026-10-26 追記)どちらの入口も、一度押しでは入らず確認を挟むようにした。`docs/confirm-outing-stop.md`
- 0:50 以降の通知(予告・1時・ロック)にはボタンをつけない
- 出る
  - アプリ画面と、外出中の通知に「帰宅した」ボタン。外出モードのときだけ押せる
  - 外出中は「外出モード(今夜だけ)」の通知に「帰宅した」ボタンをつけて出しておく。外出モードでないときは出さない
  - 夜が明けて外出モードが切れたら、この通知も消す
  - (2026-10-25 追記)当初は常駐の通知の表示を切り替えていたが、常駐の通知をなくしたので外出中だけの通知にした

## 外出中の振る舞い

| 時刻 | 外出中(帰宅を押していない) |
|---|---|
| 22:00〜 | 入浴の通知を出さない |
| 0:00 | 普段どおり「0時です / 寝る準備をしましょう」 |
| 0:50 | 予告を出さない |
| 1:00〜 | 使っていたら一度だけ「外出中でも2時までには寝ましょう」。ロックはしない。2時を過ぎてもそれ以上何もしない |

## 帰宅後

- 0時台までに「帰宅した」: 外出モードが切れて普段の流れに戻る(22時台なら入浴の通知も再開)
- 1時以降に「帰宅した」:
  - 押したときに一度だけ「おかえりなさい / 2時以降も使っていたら、10分後に画面をロックします。」と通知する
  - 2時前に押した: 2時までは何もしない。2時以降に使っていたら「2時を過ぎました / 10分後もまだ使っていたら画面をロックします。」→ 10分後も使っていたらロック
  - 2時以降に押した: 押した時点から同じ流れ(使っていたら通知 → 10分後にロック)
  - ロック後は普段どおり6時まで、ロックを解除するたびにまたロック

## 実装メモ

- 状態は `State` に夜の日付で持つ(既存の `bathDone` と同じやり方)。必要なのは「外出中の夜」と「1時以降に帰宅した夜」
- 1時以降に帰宅したら、ロック対象の開始時刻を 2:00 にする(`Schedule` に定数を足す)。1時以降は外出モードに入れないので、外出前に1時の通知を受けていることはない
- 「帰宅した」が1時以降かどうかは、押した時刻で判定する。`BathDoneReceiver.markBathDone` にならって、Receiver の companion に入口・出口の処理を置き、アプリ画面からも呼ぶ
- 通知ボタンの PendingIntent の requestCode は既存の「入浴済み」(1)と重ならないようにする。Receiver は Manifest に `exported="false"` で足す
- 判定は `Guard` に置き、`GuardTest` でテストする。`Guard` は Android に触らない方針を守る
- 足すテストの例
  - 外出中は入浴・予告・ロックがなく、0時の通知と1時の「2時までに」だけ出る
  - 朝(6時すぎ)に外出モードにしても、その日の夜に効く
  - 外出モードは次の夜には切れている
  - 0時台に帰宅すると、普段どおり1時に通知・1:10にロック
  - 1時台に帰宅すると、2時まではロックせず、2時に通知・2:10にロック
  - 1時〜6時は外出モードに入れない
- アプリ画面の説明文と状態表示に外出モードの行を足す
- README の Android 節に外出モードの説明を足す
- `/usr/bin/java` は使えないが、Homebrew の JDK を指定すればシェルからテストできる: `JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew testDebugUnitTest`
